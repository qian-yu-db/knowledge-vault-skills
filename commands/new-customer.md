Create a new customer note for: $ARGUMENTS

1. Create a new file in `02-customers/` named `customer-{CustomerName}.md`
2. Use the template from `30-templates/customer-note.md`
3. Fill in the customer name in frontmatter and title
4. Set today's date for `created` and `last_updated`
5. If an ASQ or AR number is provided, include it in the filename (e.g., `customer-NWM-AR-000100235.md`)

After creating the note, open it for the user to fill in details.
